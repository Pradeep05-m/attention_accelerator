METHODOLOGY // DISCIPLINE

How I Build Hardware

A disciplined 8-stage engineering methodology from specification analysis down to hardware-in-the-loop debugging.

01

SPECIFY

Analyze protocol specifications, memory bandwidth, latency bounds, and timing targets before writing code.

02

ARCHITECT

Partition datapaths, control units, clock domains, and FIFO buffers for optimal LUT/FF reuse.

03

RTL DESIGN

Write clean, structured, synthesizable Verilog HDL with explicit FSM states and clock domain safety.

04

SIMULATE

Execute cycle-accurate behavioral simulations in Vivado / ModelSim with protocol smoke tests.

05

VERIFY

Develop SystemVerilog testbenches, python reference golden models, and ULP tolerance checkers.

06

SYNTHESIZE

Run Vivado/Genus synthesis, inspect gate-level netlists, and optimize logic depth for setup paths.

07

IMPLEMENT

Place and route on target FPGAs (Spartan-7, PYNQ-Z2), enforcing zero setup/hold timing violations.

08

DEBUG

In-system hardware validation using logic analyzers, ILA core instantiation, and AXI stream captures.
